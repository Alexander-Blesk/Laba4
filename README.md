5. Четный индикатор

Прибор на заводе имеет две контрольные лампы, соответствующие значениям датчиков A и B. Сирена тревоги должна загораться, если ровно одна из ламп показывает нечетное значение. Запишите условие для включения сирены.

# Алгоритм и блок-схема

1. Начало
   
2. Объявить переменные и получить значение от пользователя:

  int A, B, res;
  
  scanf("%d %d", &A, &B);

3. Получаем значения переменных A,B от пользователя:

4. Сравниваем два значения:

res = (A % 2 == 0) && (B % 2 == 0);

5. Если оба значения четные то выводится:
   
1

  Иначе:
  
2

6. Конец
